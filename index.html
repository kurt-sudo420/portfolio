In active development

BadToken HYDRA

Automated LLM red-teaming framework

HYDRA is the engine inside BadToken: a scheduler and a shared evidence format that run garak, PyRIT, and a browser-based web module as one automated campaign, so every finding lands in one record you can compare and re-run. Step through a run

  • ~20,000-prompt baseline across 20 garak probe families on a locally served model
  • Results contextualized against a 23-model calibration baseline
  • Pinned vLLM serving stack on A100 nodes so runs reproduce

WebRedTeam

HYDRA's browser-based web module

Text-only scanners can't see what happens after a model's output reaches the browser. I'm extending the WebRedTeam black-box testing framework into a HYDRA module that tests whether prompt injection in page content can escalate into script execution in LLM-backed web apps.
