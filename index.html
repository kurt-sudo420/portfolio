In active development

BadToken HYDRA

Automated LLM red-teaming framework

BadToken is a Python toolkit for adversarial testing of language models. HYDRA is its engine: a scheduler and a shared evidence format that let garak, PyRIT, and a browser-based web-app module run as one automated red-team campaign, so findings from every tool land in one record you can compare and re-run.

The research question underneath it: when a model refuses a harmful request, is the refusal doing the work, or is the model simply unable to do the task?

What's done so far

  • Ran a ~20,000-prompt baseline across 20 garak probe families against a locally served instruction-tuned model.
  • Analyzed hit logs to separate genuine guardrail failures from short compliance markers that inflate attack-success rates.
  • Contextualized results with Z-scores against a 23-model calibration baseline.
  • Built the serving stack: vLLM behind an OpenAI-compatible endpoint, on a pinned CUDA/PyTorch environment so runs reproduce.
  • Designed a before/after weight-editing study (refusal-direction orthogonalization) with encoding probes as a control.
