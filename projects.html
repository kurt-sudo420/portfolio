Project BadToken

Adversarial security testing of LLMs and embedded devices · Machine Psychology Group / Cyberpunk Division, UMass Boston

In development

A Python library that puts PyRIT and garak behind one scanning and exploit API, so an adversarial evaluation can be re-run and compared rather than reconstructed from scratch each time. The research question underneath it: when a model refuses a harmful request, is that refusal doing the work, or is the model simply incapable of the task? The study answers it with a before/after weight-editing design — orthogonalizing the refusal direction and re-scanning, with encoding probes as a control.

  • ~20,000-prompt baseline across 20 probe families against a locally served instruction-tuned model
  • Hit-log analysis that separates genuine guardrail failures from compliance markers inflating attack-success rates
  • Z-score contextualization against a 23-model calibration baseline
  • Served with vLLM on A100 nodes under Slurm, on a pinned stack (vLLM 0.6.3 / torch 2.4.0 / transformers 4.46.3) so results reproduce
  • Shipping as an installable package with a config-driven scan runner, structured result schema, and report generator
  • Extending to cross-modal indirect injection — exploits carried in images rather than text

CyberToolkit

Public on GitHub

Embedded Device & Wireless Security

Machine Psychology Group / Cyberpunk Division · Faculty-supervised · Isolated hardware bench

Ongoing

The hardware half of the same research: applying the offensive red-teaming methodology behind Project BadToken to a physical attack surface, producing a device-security findings report as a companion result to the LLM work. Hands-on with the techniques I read about in advisories, so that when one shows up in an alert I know what it looks like from the other side — most recently a captive-portal rogue access point, studying how client devices behave when they associate with a spoofed SSID and what they expose on join.

  • Rogue AP / evil twin — captive-portal access point capturing associating client MAC addresses and DHCP-assigned IPs to a live monitor
  • Wi-Fi auditing — scanning, packet capture, deauthentication, and handshake analysis with Marauder, aircrack-ng, and Kismet
  • Sub-GHz RF — capture and replay for access-control and keyfob research
  • RFID / NFC — credential read, clone, and modify workflows across low- and high-frequency tags
  • BadUSB / HID — scripted payloads for physical-access and endpoint-hardening testing
Flipper Zero Marauder aircrack-ng Kismet Evil Twin / Rogue AP Sub-GHz RFID / NFC BadUSB / HID

Scope and ethics. Every asset used is owned by or explicitly authorized for the research group, and all testing happens on an air-gapped bench. Scope is reviewed by my faculty mentor before each new exploit class, and any finding with real-world implications goes through coordinated disclosure. No third-party networks, no production systems, no unauthorized targets.
